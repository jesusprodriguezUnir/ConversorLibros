# ConversorLibros

Aplicación de Windows que convierte un libro (EPUB sin DRM) en audiolibro en español, con traducción local opcional (Ollama). El audiolibro se exporta en Opus (una carpeta por libro) o M4B, para escucharlo en el móvil con cualquier reproductor de audiolibros. Todo funciona sin conexión.
